# Axel Loosme portfolio

Public career portfolio at https://axelsarassamit.github.io/.

Static HTML and CSS. No tracking, forms, third-party fonts or runtime dependencies.
Edit index.html for content and styles.css for presentation. GitHub Pages serves the main branch root.

This repository contains selected public text only. Employer configurations, original evidence documents, personal records and private application data must never be committed here.
Career stories are candidate accounts, not independent employer endorsements. The infrastructure and endpoint diagrams are conceptual illustrations.
